### Featured Engineering Projects

#### 🏥 Medicine Expiry Tracking & Transfer System (METTS)
`Laravel` · `PHP` · `Blade` · `Alpine.js` · `MySQL` · `REST API`
* **12-Module, 60-Feature Architecture:** Real-time medicine batch tracking with an automated **FEFO (First-Expired, First-Out)** engine and **QR/barcode scanning**.
* **Inter-Clinic Redistribution & Alerts:** Matches near-expiry surplus stock with high-demand clinics and triggers automated **SMS & Email** alerts in **English & Roman Urdu**.

#### 🏘️ Society Record System (WADZ)
`C++` · `OOP` · `Doubly Linked List` · `Stack`
* **Custom In-Memory Engine:** Built from scratch in C++ using a **Doubly Linked List** for active resident CRUD operations and a **Linked-List Stack** for archiving former residents.
* **Search & Reporting:** Implements linear search algorithms and recursive 2D array traversal via an interactive CLI.

#### 🚗 Car Rental Management System
`System Design` · `RBAC` · `Database Modeling`
* **5-Role Access Control:** Secures fleet bookings across Admin, Customer, Dealer, Accountant, and Invoice Manager roles with driver license verification and pre-rental checklists.
* **Automated Billing:** Handles digital agreements, invoice generation, and fleet utilization analytics.

#### 🌐 Personal Developer & Cybersecurity Portfolio
`HTML5` · `CSS3` · `JavaScript (ES6+)` · `Vercel`
* **Modular & Responsive UI:** Built from scratch with interactive category filtering (`Web`, `C++/DSA`, `Hardware`), AOS scroll reveals, typewriter animations, and direct PDF CV download.
* **Live Production:** Deployed at **[diyazehra.vercel.app](https://diyazehra.vercel.app)** with SEO metadata and Discord/email contact integration.

#### 🤖 RC Bluetooth-Controlled Car
